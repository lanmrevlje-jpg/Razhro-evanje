## 2. Odgovori na vprašanja
1. Run in Debug: Run zažene aplikacijo običajno, Debug pa omogoča razhroščevanje.
2. Breakpoint: Prekinitvena točka ustavi izvajanje programa na izbrani vrstici.
3. Step Into in Step Over: Step Into vstopi v metodo, Step Over pa izvede vrstico brez vstopa vanjo.
4. Frames: Prikazuje sklad klicev metod.
5. Variables in Watches: Variables prikazuje vrednosti spremenljivk, Watches pa spremlja izbrane izraze.
6. Operator ||: Pomeni logični ALI; pogoj je izpolnjen, če je vsaj en operand enak 42.
7. Set Value: Omogoča spremembo vrednosti spremenljivke med razhroščevanjem.
8. Evaluate Expression: Uporabimo ga za preverjanje izrazov. Metode s stranskimi učinki lahko spremenijo stanje programa.
9. NumberFormatException: Nastane lahko, ko poskušamo prazen ali neveljaven niz pretvoriti v število.
10. Deljenje z nič: Pri double dobimo Infinity ali NaN, pri int pa ArithmeticException.
